# ResuCraft Jobs

ResuCraft Jobs is the job discovery service behind ResuCraft.

It aggregates job postings from thousands of company career pages, ATS platforms, and job boards into one searchable database, making it easier to find relevant opportunities without switching between multiple websites.

### Features

- Search jobs by role, company, location, and keywords
- Browse company profiles
- Save jobs for later
- Track your application progress
- Fast REST API powering the ResuCraft platform

This repository contains the backend service that powers the Jobs feature in ResuCraft.
